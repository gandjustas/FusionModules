# MOD0006 — A module must not replace the application pipeline

**Severity:** Error · **Category:** Modulith.Design

`IWebHostBuilder.Configure` and `UseStartup` do not add to the request pipeline, they *define* it.
Calling either from a module throws away whatever the host and every other module set up —
routing included — and which module wins depends on the order of an environment variable.

## Violation

```csharp
sealed class Module : ModuleBase
{
    protected override void ConfigureServices(WebHostBuilderContext context, IServiceCollection services)
    {
        // MOD0006 — and every other module's endpoints are now gone
        context.HostingEnvironment... // via any IWebHostBuilder in scope
    }
}
```

Typically it appears while converting a service whose `Program.cs` used the older
`IWebHostBuilder` form.

## Fix

Override `Configure` instead:

```csharp
protected override void Configure(IApplicationBuilder app)
{
    app.UseMiddleware<RequestLogging>();      // middleware the module needs for itself
    app.UseEndpoints(e => e.MapGroup("/orders").MapGet("/", () => "orders"));
}
```

It runs through an `IStartupFilter`, after the host's own pipeline is in place, so routing and
authentication are already there and nothing the host or another module did is lost.
