# MOD0001 — A module must not expose public types

**Severity:** Error · **Category:** Modulith.Design

A module's types are an implementation detail. If nothing outside the module can name them,
nothing outside the module can depend on them, and the module stays replaceable — which is the
only reason to have modules at all.

This also makes [MOD0003](MOD0003.md) enforceable: the host cannot accidentally use what it
cannot see.

## Violation

```csharp
[assembly: HostingStartup(typeof(Module))]

sealed class Module : ModuleBase { }

public class Order { }   // MOD0001
```

## Fix

Make the type `internal`. The code fix does this, and Fix All does it for a whole project — which
is how a service converted into a module is usually cleaned up in one pass.

```csharp
internal class Order { }
```

If another module genuinely needs the type, it is not an implementation detail: move it to a
plain contracts library — an ordinary `Microsoft.NET.Sdk` project with no `[HostingStartup]` —
which both modules reference. That library is not a module, so this rule does not apply to it.

## Exempt by default

Types the framework reaches by reflection, which therefore cannot be internal:

- controllers (`ControllerBase`)
- page models (`PageModel`)
- view components
- tag helpers (`ITagHelper`)
- entity types configured by an `IEntityTypeConfiguration<T>` **in the same assembly**

The last one is worth dwelling on: the configuration is the evidence. A public class with no
configuration is reported, because from the outside it is indistinguishable from a leak.

## When the rule is wrong

Real solutions have public types the analyzer cannot infer a reason for: a DTO bound by a
source-generated `JsonSerializerContext` in another assembly, a SignalR hub, a gRPC service base,
a message contract a broker library discovers by reflection. Allow them by name:

```ini
# .editorconfig
[*.cs]
modulith_allowed_public_types = OrderDto, PaymentHub
```

Or suppress one occurrence:

```csharp
#pragma warning disable MOD0001 // Bound by OrderSerializerContext in Contracts.
public class OrderDto { }
#pragma warning restore MOD0001
```

Prefer the `.editorconfig` list when the exception is structural and the pragma when it is local.
Either way, write down why — the next reader cannot tell a considered exception from an
abandoned one.
