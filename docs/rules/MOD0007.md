# MOD0007 — Redundant IStartupFilter registration

**Severity:** Warning · **Category:** Modulith.Usage

`ModuleBase` registers the module as an `IStartupFilter` for you. Registering it again means
`Configure` runs twice: every piece of middleware the module adds is added twice, and every
endpoint it maps is mapped twice — which throws at startup rather than warning.

## Violation

```csharp
sealed class Module : ModuleBase
{
    protected override void ConfigureServices(WebHostBuilderContext context, IServiceCollection services)
    {
        services.AddSingleton<IStartupFilter>(this);   // MOD0007 — ModuleBase already did this
        services.AddControllersWithViews().AddApplicationPart(typeof(Module).Assembly);
    }
}
```

## Fix

Delete the line. The code fix does it.

## Where it comes from

Hand-written modules that predate `ModuleBase` did this themselves, and the line survives the
conversion because it looks load-bearing. It was, once.
