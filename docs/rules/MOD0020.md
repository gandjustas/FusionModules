# MOD0020 — The Modulith package is not referenced

**Severity:** Warning · **Category:** Modulith.Design

This assembly declares `[assembly: HostingStartup]`, but the `ModuleBase` type is not in the
compilation. The analyzers are running without the runtime package, so every rule that depends on
knowing what a module is — [MOD0002](MOD0002.md), [MOD0003](MOD0003.md), [MOD0005](MOD0005.md) —
is inactive. The build is green because nothing is being checked.

## Fix

```
dotnet add package Modulith
```

## Why it is a warning and not an error

An assembly may legitimately carry a hosting startup without being a Modulith module — a library
that configures telemetry for whoever hosts it, for instance. There the warning is noise, and
turning it off is the right answer:

```ini
# .editorconfig
dotnet_diagnostic.MOD0020.severity = none
```
